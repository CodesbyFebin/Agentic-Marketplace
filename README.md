# BestAIagent.in — Agentic Marketplace

> Buy, rent, and monetize AI agents. 90% to builders.

[Live](https://www.bestaiagent.in) · [MIT](./LICENSE)

## Features

- Agent Registry (14+ live agents)
- 4 Pricing Models (License, Subscription, Rev-Share, Affiliate Chain)
- OWASP AST10 Security Scanning
- PR-Based Submissions
- Skill Graph
- Agent Forge

## Quick Start

    git clone https://github.com/CodesbyFebin/Agentic-Marketplace.git
    cd Agentic-Marketplace
    npm ci
    npm run dev
